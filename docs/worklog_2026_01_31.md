# 작업 로그
2026-01-31

## 목표
- Milvus 벡터 검색과 Postgres(Cloud SQL) 메타/FTS 연동 구조 정리
- 수집·인덱싱·조회 흐름을 운영 관점에서 문서화

## 변경 사항
- Milvus 연결/조회 구성 정리:
  - `services/stores/milvus_store.py`에서 `MILVUS_HOST/PORT/USER/PASSWORD/SECURE`로 연결.
  - 컬렉션 이름은 `poi_{category}`(prefix는 `MILVUS_COLLECTION_PREFIX`)로 구성.
  - 검색은 IP metric 기반, `ef >= max(64, top_k)`로 보정.
- Postgres 메타/FTS 구성 정리:
  - `services/stores/postgres_store.py`가 `DATABASE_URL`/`POSTGRES_DSN`으로 연결.
  - `poi_meta` 테이블에서 메타/좌표/인기도/FTS(search_vector) 조회.
  - `fetch_meta`, `fetch_names`, `fts_scores`(plainto_tsquery, simple) 제공.
- 검색/추천 연동 정리:
  - `MilvusScorer`가 Milvus로 dense 후보를 받고 Postgres로 메타/좌표 보강.
  - `retriever.py`는 Milvus dense + Postgres BM25 결과를 ALPHA 비율로 결합.
- 수집 파이프라인 정리:
  - `scripts/milvus/ingest_poi_embeddings.py`로 임베딩 → Milvus (HNSW/IP).
  - `scripts/db/ingest_poi_meta.py`로 embedding_json → `poi_meta` upsert 및 FTS 생성.
- 인프라 구성 확인:
  - `terraform/main.tf`에 Cloud SQL(Postgres 15) 및 Milvus VM + 방화벽(19530/9091).

## 설정/환경변수
- Milvus: `MILVUS_HOST`, `MILVUS_PORT`, `MILVUS_USER`, `MILVUS_PASSWORD`, `MILVUS_SECURE`, `MILVUS_COLLECTION_PREFIX`
- Postgres: `DATABASE_URL` 또는 `POSTGRES_DSN`
- 스위치: `USE_MILVUS` (없으면 `MILVUS_HOST` 존재 시 Milvus 사용)
