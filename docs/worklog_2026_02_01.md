# 작업 로그
2026-02-01

## 목표
- 행동 로그 기반 recency 적용 준비(가중치/시간감쇠/부정 신호 포함)
- 기존 요청 데이터 유지하면서 에러 없이 동작하도록 확장

## 변경 사항
- 사용자 입력 모델에 행동 이벤트 스키마 추가(`behaviorEvents`) 및 방문 이력에 `visitedAt` optional 필드 추가.
- RecommendService에서 이벤트 가중치/시간감쇠 계산 로직 추가 후 behavior 기반 가중치 생성.
- scorer들이 `recent_place_weights`를 받아 가중 평균 recency 벡터를 사용하도록 확장(없으면 기존 방식 fallback).
- dwell time은 최소값 기준/로그 스케일로 가중치 계산, 부정 신호는 음수 가중치로 반영.

## 설정/환경변수
- `HISTORY_HALF_LIFE_DAYS`, `BEHAVIOR_HALF_LIFE_DAYS`
- `BEHAVIOR_WEIGHT_CLICK`, `BEHAVIOR_WEIGHT_VIEW`, `BEHAVIOR_WEIGHT_LIKE`, `BEHAVIOR_WEIGHT_BOOKMARK`, `BEHAVIOR_WEIGHT_HIDE`, `BEHAVIOR_WEIGHT_DISLIKE`, `BEHAVIOR_WEIGHT_SKIP`
- `BEHAVIOR_DWELL_MIN_SECONDS`, `BEHAVIOR_DWELL_REF_SECONDS`, `BEHAVIOR_DWELL_MIN_WEIGHT`, `BEHAVIOR_DWELL_MAX_WEIGHT`

## 상세 설명

### 입력 데이터
- `history_places`
  - 필드: `place_id`, `category`, `visited_at`
  - 현재 recency 가중치에는 **직접 사용하지 않고**, 방문 이력 제외(`exclude_place_ids`)에만 사용.
- `behavior_events`
  - 필드: `place_id`, `category`, `event_type`, `occurred_at`, `dwell_seconds`

### 이벤트 정규화
- `event_type`는 alias 매핑 후 canonical 타입으로 변환
  - 예: `dwell_time`, `dwelltime`, `stay`, `scroll` -> `dwell`
  - 정의되지 않은 타입은 가중치 0으로 무시

### 가중치 계산
- 이벤트 기본 가중치: `BEHAVIOR_WEIGHT_*`에서 조회
- 체류 시간(`dwell`) 가중치
  - `dwell_seconds < BEHAVIOR_DWELL_MIN_SECONDS`이면 0
  - 로그 스케일:
    - `scaled = log1p(min(dwell, ref)) / log1p(ref)`
    - `weight = min_weight + (max_weight - min_weight) * scaled`
- 시간 감쇠(Time Decay)
  - `decay = exp(-delta_days / half_life_days)`
  - `delta_days = (now - occurred_at) / 86400`
- 장소별 누적: 동일 `place_id`의 가중치를 합산
- 음수 가중치 허용: `hide/dislike/skip`은 추천 점수에서 감점 효과

### 점수 반영
- `recent_place_weights` -> 가중 평균 recency 벡터 생성
  - `weighted_vec = sum(w_i * emb_i)` 후 L2 정규화
- 최종 점수에 가산
  - `score_recent = recent_weight * dot(embeddings, recent_vec)`
- `recent_place_weights`가 없으면 `recent_place_ids`로 단순 평균 벡터 fallback

### 적용 위치 (코드)
- `fastapi_app/services/recommend_service.py`
  - `_build_recent_place_weights()`에서 behavior_events 가중치 생성
  - `recommend()`에서 scorer로 `recent_place_weights` 전달
- `fastapi_app/services/scorers/base.py`
  - `topk()`에서 recency 벡터를 계산하고 점수에 합산
